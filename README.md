# NOVA AI Assistant

Original AI assistant chat interface built with React, TypeScript, Vite, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this repository into Vercel. Vercel will detect Vite automatically.

The current assistant response is a frontend demo. Connect `submit()` in `src/App.tsx` to your real AI Agent backend/API when ready.

## Features

- NOVA-branded AI chat interface
- Floating rounded composer
- Attachment/action menu
- Voice input UI
- Enter / Shift+Enter handling
- Auto-expanding textarea
- Responsive mobile design
- Quick action suggestions
- New chat control
